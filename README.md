# github-final-project

## Simple Interest Calculator

A Bash script that calculates simple interest from a principal amount,
an annual rate of interest, and a time period in years.

### Formula
Simple Interest = (Principal × Rate × Time) / 100

### Usage
    chmod +x simple-interest.sh
    ./simple-interest.sh

The script prompts for the principal, rate, and time, then prints the result.
